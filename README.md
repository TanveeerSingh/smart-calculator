# Smart Calculator
Hello! Welcome to Advanced Smart Calculator v2.0 - Fast & Easy!

This is a small calculator I made in Python for my UCS 745 Cloud and DevOps lab.
It can add, subtract, multiply and divide two numbers. Division by zero is
also handled, so the program shows an error instead of crashing.

The main purpose of this project was not really the calculator itself.
I used it to practice Git and GitHub - creating branches, merging them,
and resolving a merge conflict that I created on purpose by changing the
welcome message in two branches at the same time. The full story of the
conflict and how I resolved it is in my lab assignment file.

## How to run
```
python3 calculator.py
```
